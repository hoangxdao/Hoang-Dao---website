# hoangdao-website

Personal website of Hoang Dao, PhD (Phenikaa University, Hanoi), served at https://hoangdao.pages.dev by Cloudflare Pages.

- `index.html`: the whole site (single page, hash routes)
- `site-data.js`: research, books, courses, apps, CV data
- `posts.js`: blog posts for *Ceteris Paribus, Mostly* (updated weekly)
- `img/`: photos

Cloudflare Pages settings: no build command, output directory `/`.
